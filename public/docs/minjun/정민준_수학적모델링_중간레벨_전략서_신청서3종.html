기초 레벨

로지스틱 이계도함수

P(t)=K/(1+Ae⁻ʳᵗ) 수식을 주어진 파라미터로 계산하고, 이계도함수 P''(t)=0인 변곡점 t*=ln(A)/r을 도출. 파이썬으로 곡선 그리기.

★ 중간 레벨 (이 파일)

파라미터 피팅 + 다품종 비교

실제 상추·토마토 생장 공공 데이터에 curve_fit으로 K, r, A를 피팅. 품종마다 r값이 다른 것을 비교. R² 적합도로 모델 신뢰도 정량화.

심화 레벨

SIR 연립 미분방정식

dS/dt=-βSI, dI/dt=βSI-γI 연립 방정식 구성. scipy.odeint로 수치해. 실제 역학 데이터로 β·γ 역산 피팅. R₀=β/γ 수식 도출.

여름방학 공부 로드맵

주제 1 — 파라미터 피팅

최소제곱법 피팅
2주 계획

  • 1주: 최소제곱법 개념 — "데이터와 모델의 차이(잔차)의 제곱합을 최소화한다"는 아이디어. scipy.optimize.curve_fit 사용법
  • 2주: 실제 데이터 적용 — 농촌진흥청 공공 데이터에서 상추·토마토·시금치 3품종 생장 데이터 수집. 품종별 r값 비교표 작성. R² 계산 및 해석
참고: SciPy curve_fit 공식 문서 → 농촌진흥청 농업기술포털 (품종별 생장 데이터) → numpy polyfit 비교
주제 2 — 수치적분

리만합 오차 분석
2주 계획

  • 1주: 리만합 원리 — n등분 분할, 좌·우·중점 리만합. 분할 수 n이 커질수록 오차가 줄어드는 이유 (수열의 극한과 연결). 사다리꼴 법칙과 심프슨 법칙 비교
  • 2주: 파이썬 구현 — 실제 태양광 발전량 시계열 데이터로 일별 누적 발전량을 각 방법으로 계산. 분할 수 n에 따른 오차 수렴 그래프 시각화
참고: Khan Academy "Riemann Sums" → SciPy integrate.trapezoid / simps 문서 → 기상청 공공데이터 태양광 발전량
주제 3 — 민감도 분석

dT/dr 해석적 미분
1~2주 계획

  • 1주: 지수 감소 모델에서 T를 r의 함수로 표현하고 dT/dr을 해석적으로 미분. "감소율 r이 1% 증가하면 탄소예산 소진 시점 T가 몇 년 연장되는가"를 수식으로 계산
  • 2주: 민감도 곡선 시각화 — r에 따른 T 변화 그래프. 현재 감축 속도 r₀ 주변에서 민감도가 특히 높은 이유 분석. NDC 목표값 r_NDC에서의 dT/dr 수치 계산
참고: 미적분 교과서 도함수 단원 → IPCC AR6 Technical Summary → matplotlib 그래프 공식 문서

중간 레벨 면접 예상 질문

중간 레벨 면접의 특징: 기초보다 한 단계 깊은 질문이 나옵니다. "왜 이 파라미터인가?", "오차가 얼마인가?", "수치가 달라지면 결론이 달라지는가?" — 이 세 유형이 핵심입니다.
주제 1 — 파라미터 피팅

예상 면접 질문

  • R²=0.97이 나왔다면, 나머지 3%는 무엇이 설명하지 못하는 오차인가?
  • 상추와 토마토의 r값이 다른데, 어떤 품종이 스마트팜에서 더 유리한가? 왜?
  • curve_fit이 최적 파라미터를 찾는 원리는? 최소제곱법이 왜 "제곱"을 쓰는가?
  • 피팅한 변곡점 t*가 실제 수확 시점과 얼마나 일치했는가?
주제 2 — 수치적분

예상 면접 질문

  • 분할 수 n이 2배 늘면 사다리꼴 오차는 몇 배 줄어드는가? 수식으로 설명하면?
  • 심프슨 법칙이 사다리꼴보다 정확한 이유는 수학적으로 무엇인가?
  • ESS에서 누적 발전량 계산이 왜 중요한가? 오차가 크면 충방전 전략에 어떤 영향을 미치는가?
  • 실제 태양광 데이터에서 발전량이 0인 구간(야간)을 어떻게 처리했는가?
주제 3 — 민감도 분석

예상 면접 질문

  • dT/dr을 계산하면 양수가 나오는데, 그 물리적 의미는 무엇인가? (감소율 r이 클수록 탄소예산 소진 시점 T가 늦어짐)
  • 현재 감축 속도 r₀에서 dT/dr의 절댓값이 크다면, 정책적으로 어떤 의미인가?
  • 지수 감소 모델에서 r이 두 배가 되면 T는 어떻게 변하는가? 비례 관계인가?
  • 민감도 분석이 "정책 결정에 왜 유용한가"를 한 문장으로 설명하면?
수능 후 7일: 각 주제당 핵심 수치(R² / 오차율 / dT/dr 계산값)를 암기해두세요. 면접에서 구체적인 숫자를 말하는 것이 "진짜 탐구한 학생"의 가장 강한 증거입니다.

지원동기 고등학교 2학년 때 '더 클래식' 활동에서 탄소 배출량 감소와 기후변화 대응을 탐구하고, 지수 감소 모델의 정적분으로 탄소예산 소진 시점 T를 계산했습니다. 그러나 "감소율 r이 조금 달라지면 T가 얼마나 달라지는가?"라는 민감도 질문에는 답하지 못했습니다. 이 질문은 dT/dr — 즉 T를 r의 함수로 보고 미분하는 것으로 해결할 수 있으며, 이는 정적분과 미분을 결합하는 탐구입니다.

이 프로그램을 통해 T(r)를 r의 함수로 표현하고 dT/dr을 해석적으로 미분하여 "현재 감축 속도에서 감축률 1% 포인트 상승이 탄소예산 소진을 몇 년 연장하는가"를 정량화하고, 이를 NDC 목표 달성 가능성 판단에 적용하고자 지원합니다.

【포착한 현상】

기사는 탄소 감축 속도가 조금만 달라져도 기온 상승 결과가 크게 달라진다고 경고하지만, "감소율 r이 1% 포인트 달라질 때 탄소예산 소진 시점 T가 정확히 몇 년 달라지는가"를 수학적으로 계산한 내용은 없습니다. 지수 감소 모델에서 T(r)은 r의 함수로 표현할 수 있고, 이를 미분하면 dT/dr이 도출됩니다. 이 민감도 계수가 크면 "감축 속도 조금만 달라져도 T가 크게 변한다"는 기사의 주장이 수학적으로 증명됩니다.

▶ STEP 1. T(r) 함수 도출 (6월 1주 + 여름방학 1주)

· C₀ = 6.5억 tCO₂eq (한국 2023년), B_KR = 400Gt × 1.7% ≈ 6.8Gt (※ IPCC AR6 400Gt는 2020년 기준; 탐구에서 보수적 상한 6.8Gt 사용)

· ∫₀^T C₀e^(−rt)dt = B → (C₀/r)(1 − e^(−rT)) = B

· 정리하면: T(r) = −(1/r) · ln(1 − Br/C₀)

· 이것이 "r을 주면 T가 나오는 함수"임을 파이썬으로 확인 (r값 바꿔가며 T 계산)

▶ STEP 2. dT/dr 해석적 미분 (여름방학 1주)

· T(r) = −(1/r)·ln(1 − Br/C₀)를 r에 대해 미분

· 몫의 법칙 + 연쇄법칙 + 로그함수 미분 적용

· 결과: dT/dr = (1/r²)·ln(1 − Br/C₀) + B/(C₀ − Br) · (−1/r)

· Python sympy로 검증 — 손 계산과 일치하는지 확인

【기대 효과】

· 수학적 측면: 적분으로 구한 T(r)을 다시 r에 대해 미분하는 "적분과 미분의 결합"이 현실 문제(정책 민감도)에 어떻게 쓰이는지를 직접 체험.
