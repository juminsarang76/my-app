주제 1 — 이계도함수
강점: 담임 교사가 원하는 학과 타겟팅이 가장 명확. 이계도함수→변곡점→수확 시점의 논리가 한 줄로 설명됨.

약점: "스마트팜·농업" 색채가 강해 입시상담사 우려 지점. 1학년 ICT 탐구와의 연결이 2학년보다 약함.
주제 2 — 합성함수 미분
강점: 2학년 태양광·ESS 탐구와 완벽 연결. "정오에 최대라는 상식이 틀렸다"는 발표 임팩트. 입시상담사 에너지 키워드 부합.

약점: 연쇄법칙 손 계산을 완전히 이해해야 면접 통과. 삼각함수 미분 포함.
주제 3 — 정적분
강점: 프로그램 목적("기사 비판적 분석")에 가장 부합. IPCC·환경부 보도자료를 수학으로 검증하는 구조. 글로벌 스케일.

약점: 탄소예산 한국 몫 배분 기준에 대한 추가 논리 필요.
⚠️ 공통 주의 사항
세 주제 모두 "이해 없이 형식만 갖추면 면접에서 역효과". 핵심 개념(이계도함수 / 연쇄법칙 / 정적분)을 손으로 직접 계산하고 설명할 수 있어야 함. 파이썬 시각화 코드도 한 줄씩 설명 가능해야 함.
두 조언자 의견 균형점: 입시상담사(에너지·데이터 키워드 유지) × 담임교사(학과 타겟팅)를 동시에 만족하는 최적 조합은 주제 1 + 주제 3입니다. 주제 1은 농업(학과 타겟팅), 주제 3은 환경·기후(글로벌 데이터)를 커버하며 미적분 개념도 겹치지 않습니다.

▶ STEP 1. 모델 설정 (6월 1주)

P(t) = K/(1+Ae^(−rt)) 도입. 농촌진흥청 공공 데이터로 파라미터 K, r, A 추정.

▶ STEP 2. 1계 도함수 분석 (6월 2주)

P'(t) = rKAe^(−rt)/(1+Ae^(−rt))² 도출. 생장 속도 최댓값 계산. matplotlib으로 시각화.

▶ STEP 3. 이계도함수 → 최적 수확 시점 (6월 3주)

P''(t) = 0인 변곡점 t* = ln(A)/r 계산. 변곡점 전후 오목·볼록 확인. t*가 최적 수확 신호임을 증명.

▶ STEP 4. 환경 변수 변화 분석 (6월 4주)

고온(r↑) → t* 앞당겨짐, 저광량(r↓) → t* 늦어짐. 스마트팜 환경 제어가 r값을 관리하여 t*를 조절하는 것임을 수학적으로 증명.

▶ STEP 5. 한계 분석 및 스마트시스템 연결 (7월 1주)

단일 변수 모델 한계 → 다변수 모델 필요 → 데이터 사이언스가 필요한 수학적 이유.
