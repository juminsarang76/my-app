【포착한 현상】

기사는 SIR 모델이 감염병 확산 예측에 쓰이지만 실제 유행 곡선과 괴리가 생기는 이유로 "파라미터 추정의 어려움"을 언급합니다. 그러나 SIR 모델의 연립 미분방정식이 무엇이며, 감염 정점 시점이 수학적으로 어떤 조건에서 결정되는가에 대한 설명은 없습니다. 감염자 I(t)가 최대가 되는 순간은 dI/dt = 0인 시점이며, 이를 분석하면 R₀의 의미가 자연스럽게 도출됩니다.

· C₀ = 6.5억 tCO₂eq (한국 2023년 배출량, 환경부 자료)

· B_KR = 400Gt × 1.7% ≈ 6.8Gt (한국 몫, 현재 배출량 비중 기준 ※ 인구 비중 0.63%, GDP 비중 1.6%, 현재 배출량 비중 1.76% 중 현재 배출량 기준 채택. IPCC 400Gt는 2020년 기준값.)

· 모델 A: C_A(t) = C₀·e^(−rt) / 모델 B: C_B(t) = max(C₀−at, 0) / 모델 C: NDC 반영 계단형

▶ STEP 2. 정적분 수식 도출 (여름방학 1~2주)

· F_A(T) = (C₀/r)(1 − e^(−rT)),  F_B(T) = C₀T_n − (a/2)T_n²

· 각 수식 손 계산 도출 → Python sympy로 검증

▶ STEP 3. 이분법으로 T와 경계 감소율 r* 역산 (여름방학 2주)

· 이분법: g(T) = F(T) − B = 0인 T를 [T_lo, T_hi]에서 이진 탐색. 수렴 조건 |g(T_mid)| < 10⁻⁶

· scipy.optimize.brentq(g, T_lo, T_hi) 적용. 수렴 과정 단계별 표 작성

· 경계 감소율 r*: C₀/r − B = 0 → r* = C₀/B 해석적 도출 후 수치해와 비교

▶ STEP 4. 시나리오별 결과 비교 및 시각화 (여름방학 3주)

· 세 모델별 T(탄소예산 소진), T_n(탄소중립), r* 비교표 작성
