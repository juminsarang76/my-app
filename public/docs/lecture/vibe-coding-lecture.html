// Section 01

바이브코딩이란?

말 그대로 "바이브(느낌, 감각)"로 코딩하는 방법입니다. AI에게 자연어로 원하는 것을 설명하면, AI가 코드를 대신 작성해 줍니다.

🎯 핵심 개념 한 줄 요약

"내가 원하는 것을 말하면, AI가 코드로 만들어주는 것"

🧠

AI가 코드를 씁니다

여러분은 "할 일 목록 앱 만들어줘"라고 말하기만 하면 됩니다. ChatGPT, Claude, Cursor 같은 AI가 실제로 작동하는 코드를 자동으로 생성합니다.

🎨

여러분은 기획·방향을 잡습니다

어떤 기능이 필요한지, 어떤 느낌이어야 하는지, 무엇을 고쳐야 하는지 — 판단과 방향은 사람이 합니다. AI는 실행자입니다.

⚡

왜 지금 바이브코딩인가?

2023년 이후 AI의 코드 생성 능력이 폭발적으로 향상됐습니다. 이제는 전문 개발자도 바이브코딩을 사용해 개발 속도를 10배 이상 높입니다. 비전공자가 앱을 직접 출시하는 사례가 급증하고 있습니다.

✅ 바이브코딩으로 만들 수 있는 것들

  • 웹사이트 / 포트폴리오 페이지
  • 할 일 관리 / 가계부 / 일정 관리 앱
  • 데이터 시각화 대시보드
  • 간단한 게임 (퀴즈, 카드게임 등)
  • 자동화 스크립트 (엑셀 정리, 이메일 발송 등)
  • 챗봇 / AI 기반 도구
// Section 02

기존 코딩 vs 바이브코딩

같은 목표를 달성하는 두 가지 방식을 비교해봅니다.

항목 기존 코딩 바이브코딩
진입 장벽프로그래밍 언어 문법을 6개월~수년 공부해야오늘 당장 시작 가능
작업 방식코드를 직접 한 줄씩 작성AI에게 원하는 것 설명 → 코드 생성
오류 해결직접 디버깅 (원인 파악 필요)오류 메시지를 AI에게 붙여넣기
속도간단한 기능도 수 시간~수 일기본 앱 수 분~수 시간
한계이론상 제한 없음복잡한 대규모 시스템은 어려움
필요 역량논리적 사고 + 언어 문법명확한 설명 능력 + 판단력
💡
오해하지 마세요! 바이브코딩은 "코딩의 쉬운 버전"이 아니라 완전히 다른 방식의 개발 접근법입니다. 아이디어를 빠르게 현실로 만드는 데 특화되어 있습니다.
// Section 03

사전지식 — 꼭 알아야 할 것들

코딩은 몰라도 됩니다. 그러나 아래 개념들은 알면 훨씬 쉽게 진행됩니다.

1

웹의 작동 방식 (초간단 버전)

브라우저(크롬)가 서버에 요청을 보내면 → 서버가 HTML/CSS/JS 파일을 보내줌 → 브라우저가 화면에 그려줌. 이 흐름만 이해하면 됩니다.

// 웹 3요소 HTML → 뼈대 (내용, 구조) CSS → 옷 (색깔, 디자인) JS → 근육 (움직임, 기능)
2

파일과 폴더 구조 이해

프로젝트는 폴더 안에 여러 파일이 모인 것입니다. index.html, style.css, script.js처럼 각각 역할이 나뉩니다. AI가 파일을 여러 개 만들어줄 때 각각 어디에 저장할지 알아야 합니다.

3

터미널(명령창) 기초

검은 창에 텍스트를 입력해서 컴퓨터를 제어하는 도구입니다. 딱 4가지 명령어만 알면 됩니다.

cd 폴더이름 # 폴더 이동 ls # 현재 폴더 목록 보기 npm install # 패키지 설치 npm run dev # 개발 서버 실행
4

오류 메시지를 두려워하지 않기

오류 메시지는 "뭔가 잘못됐다"는 신호일 뿐, 컴퓨터가 화낸 게 아닙니다. 오류 메시지 전체를 복사해서 AI에게 주면 바이브코딩에서는 대부분 해결됩니다.

🌐 유용한 용어 정리

API 프로그램끼리 대화하는 방법. "날씨 API"처럼 외부 서비스를 내 앱에서 쓸 때
라이브러리 남이 만들어둔 기능 묶음. 직접 만들 필요 없이 가져다 씀
배포(Deploy) 내 컴퓨터에서만 보이던 앱을 인터넷에 올려 누구나 볼 수 있게 하는 것
리포지터리 코드 저장소. GitHub에 올리는 프로젝트 폴더
// Section 04

환경 셋업

가장 빠르게 바이브코딩을 시작할 수 있는 두 가지 경로를 안내합니다.

🛣 두 가지 경로

① 브라우저만으로 시작 (추천 — 설치 없음)  |  ② 로컬 편집기 설치 (더 강력)

경로 ① — 브라우저만으로 시작하기

STEP 1

Claude.ai 또는 ChatGPT 계정 만들기

무료 계정으로 충분히 시작 가능합니다. claude.ai에서 회원가입 후 로그인.

STEP 2

CodeSandbox 또는 StackBlitz 접속

브라우저에서 바로 코드를 실행할 수 있는 온라인 편집기입니다. codesandbox.io 에 접속 → "Create Sandbox" → "Vanilla JS" 선택.

STEP 3

AI에게 코드 받아서 붙여넣기

AI에게 원하는 앱 설명 → 코드 복사 → CodeSandbox에 붙여넣기 → 바로 실행 확인.

경로 ② — Cursor 설치 (추천 도구)

⬇️

설치

cursor.com 접속 → 다운로드 → 설치. VS Code와 거의 동일한 UI라 익숙해지기 쉽습니다.

🤖

AI 채팅 열기

Cursor 안에서 Ctrl+K 또는 Ctrl+L을 눌러 AI 채팅창을 엽니다. 여기서 원하는 걸 말하면 코드가 자동 생성됩니다.

📦

Node.js 설치 (선택)

React나 Next.js 앱을 만들려면 필요합니다. nodejs.org에서 LTS 버전 다운로드 후 설치. 설치 후 터미널에서 node -v 입력해 확인.

🔑

API 키 설정 (선택)

Cursor 무료 플랜으로도 충분합니다. Claude나 GPT API 키를 직접 연결하면 더 강력하게 사용 가능합니다.

⚠️
강의장 안내: 오늘 실습은 CodeSandbox (브라우저)로 진행합니다. 설치 없이 바로 시작 가능합니다. 집에서 계속 공부할 분은 Cursor를 설치해 보세요.
// 강의 1단계

프롬프트 기초

AI에게 잘 말하는 것이 바이브코딩의 핵심 스킬입니다. 같은 요청도 어떻게 쓰느냐에 따라 결과가 완전히 달라집니다.

📐 좋은 프롬프트의 4가지 요소

① 목적
무엇을 만들고 싶은지 명확히
② 대상
누가 사용하는 앱인지
③ 기능
구체적인 기능 목록
④ 스타일
디자인, 색감, 분위기

❌ 나쁜 프롬프트 vs ✅ 좋은 프롬프트

BAD PROMPT
할 일 앱 만들어줘

너무 모호합니다. AI가 어떤 스타일로, 어떤 기능을 넣어야 할지 모릅니다.

GOOD PROMPT
할 일 관리 웹앱을 만들어줘. 기능: - 할 일 추가, 삭제, 완료 표시 - 완료된 항목은 취소선 표시 - 미완료 항목 개수를 상단에 표시 - 로컬스토리지에 저장 (새로고침해도 유지) 디자인: - 다크 배경, 보라색 포인트 색상 - 모바일에서도 잘 보이게 - 한국어 UI 기술: - 순수 HTML/CSS/JS (라이브러리 없이) - 하나의 index.html 파일로 완성
실습 1

나만의 첫 번째 프롬프트 작성하기

  • 종이에 내가 만들고 싶은 앱을 떠올려보기
  • 위의 4가지 요소(목적/대상/기능/스타일)를 채워서 프롬프트 작성
  • 옆 사람과 프롬프트 교환해서 읽어보기 — 이해가 되는가?
// 강의 2단계

첫 번째 앱 만들기

실제로 AI에게 코드를 받아서 브라우저에서 실행해봅니다.

STEP 01

CodeSandbox 열기

codesandbox.io 접속 → Sign in with Google → Create Sandbox → Vanilla JS 선택

STEP 02

Claude에게 프롬프트 입력

claude.ai 열고 준비한 프롬프트를 입력. "하나의 HTML 파일로 만들어줘"를 꼭 추가하세요.

STEP 03

코드 복사 → 붙여넣기

AI가 준 코드 블록 전체 복사 → CodeSandbox의 index.html에 전부 붙여넣기

STEP 04

실행 확인

오른쪽 미리보기 창에서 앱이 작동하는지 확인. 마음에 안 들면 AI에게 수정 요청!

STEP 05

반복 개선 (이터레이션)

"버튼 색깔을 파란색으로 바꿔줘", "글씨 크기를 키워줘" 같은 수정을 계속 요청해서 완성도를 높입니다.

💬 수정 요청 프롬프트 패턴

# 기능 추가 "~~ 기능을 추가해줘" # 디자인 수정 "~~가 너무 크다 / 작다 / 이상하다. 고쳐줘" # 오류 전달 "이런 오류가 생겼어: [오류 메시지 붙여넣기]" # 전체 재작성 "이 코드 전체를 더 깔끔하게 다시 써줘"
실습 2

퀴즈 앱 만들기 (30분)

  • Claude에게 5문제짜리 OX 퀴즈 앱 만들어달라고 요청
  • 직접 원하는 문제 내용으로 바꿔보기
  • 점수 표시 기능 추가 요청해보기
  • 완성된 앱을 이웃과 공유해보기
// 강의 3단계

오류 해결법

바이브코딩에서 오류는 일상입니다. 당황하지 않고 처리하는 방법을 익힙니다.

🔴

화면이 하얗게 비어있다

HTML 구조가 잘못됐거나 JS 오류로 실행이 중단됐습니다. 브라우저 콘솔(F12)을 열어 빨간 메시지를 AI에게 전달하세요.

🟡

기능이 작동하지 않는다

버튼을 눌러도 반응이 없는 경우. "버튼을 클릭해도 아무것도 안 돼. 이 코드에서 문제를 찾아줘"라고 요청.

🟣

디자인이 이상하다

스크린샷을 AI에게 첨부하거나, 어떤 부분이 어떻게 이상한지 텍스트로 설명하면 됩니다.

🟢

AI가 계속 틀린 코드를 준다

대화를 새로 시작하거나, "이전 방식은 안 됐어. 완전히 다른 접근 방법으로 다시 만들어줘"라고 요청.

🛠 오류 해결 3단계 공식

1

오류 메시지 캡처하기

F12 (개발자 도구) → Console 탭 → 빨간 글씨 전체 복사

2

AI에게 전달하기

"이런 오류가 생겼어: [오류 메시지]" + 현재 코드 붙여넣기

3

수정된 코드로 교체하기

AI가 준 새 코드로 전체 또는 해당 부분만 교체

실습 3

의도적으로 오류 만들고 고쳐보기

  • 지난 실습 코드에서 태그 하나를 일부러 지워서 오류 발생시키기
  • F12 콘솔에서 오류 메시지 확인하기
  • 오류 메시지를 AI에게 전달해서 해결하기
  • "어떤 부분을 수정했는지 설명해줘"라고 물어보기
// 강의 4단계

실전 프로젝트

지금까지 배운 것을 모아 처음부터 끝까지 하나의 완성된 앱을 만들어봅니다.

🎯 오늘의 최종 프로젝트: 나만의 포트폴리오 사이트

  • 내 이름, 한줄 소개, 사진(또는 이모지 아바타)
  • 관심 분야 / 보유 스킬 섹션
  • 진행한 프로젝트 카드 (이번 강의 실습 앱 소개!)
  • 연락처 / SNS 링크
  • 모바일 반응형 디자인

단계별 프롬프트 전략

PHASE 1 — 뼈대 만들기
내 포트폴리오 웹사이트를 만들어줘. 이름: [내 이름] 소개: [한 줄 소개] 색상: 다크 배경에 민트 포인트 섹션 구성: - 상단 히어로 (이름 + 소개) - 스킬 카드들 - 프로젝트 섹션 - 연락처 HTML/CSS/JS 하나의 파일로, 애니메이션 포함
PHASE 2 — 콘텐츠 채우기
스킬 섹션에 다음 항목들을 추가해줘: [내가 잘하는 것들 목록] 프로젝트 섹션에 카드를 3개 만들어줘: 1. [프로젝트 이름] — [설명] 2. ...
PHASE 3 — 디자인 개선
스크롤하면 각 섹션이 부드럽게 나타나는 페이드인 애니메이션을 추가해줘. 상단 네비게이션 바도 추가해줘 (스크롤하면 배경이 생기는 효과 포함).
실습 4 — 메인 프로젝트 (60분)

나만의 포트폴리오 사이트 완성하기

  • 위 단계를 따라가며 포트폴리오 페이지 제작
  • 최소 3번 이상 AI에게 수정 요청 반복하기
  • 완성 후 이웃과 서로 URL 공유하기
  • 마음에 드는 포인트 하나, 고치고 싶은 점 하나 발표

Netlify Drop 배포 (가장 빠른 방법)

01

app.netlify.com/drop 접속

로그인 없이도 배포 가능합니다.

02

폴더 드래그앤드롭

내 프로젝트 폴더(index.html이 있는 폴더)를 화면에 그냥 끌어다 놓습니다.

03

URL 받기

30초 안에 random-name.netlify.app 형식의 URL이 생성됩니다.

// Bonus

잘 쓰는 팁 모음

강의를 통해 정리한 바이브코딩을 더 잘 활용하는 팁들입니다.

🎯

작게 시작해서 키워가기

처음부터 "완벽한 앱"을 요구하지 마세요. "버튼 하나만 있는 가장 단순한 버전부터 만들어줘"로 시작해서 기능을 하나씩 추가하는 방식이 훨씬 효율적입니다.

💾

코드를 자주 저장해두기

잘 되던 코드를 메모장이나 별도 파일에 백업해두세요. AI가 수정하다가 기존 기능을 망가뜨리는 경우가 종종 있습니다. 돌아올 수 있는 버전이 있으면 안심됩니다.

🔁

"설명해줘"를 적극 활용하기

코드를 받은 후 "이 코드가 어떻게 작동하는지 초등학생도 이해할 수 있게 설명해줘"라고 물어보세요. 이해하면 다음에 더 잘 요청할 수 있게 됩니다.

🧩

한 번에 너무 많이 바꾸지 않기

수정 요청은 한 번에 하나씩 하는 게 좋습니다. "색깔도 바꾸고 폰트도 바꾸고 레이아웃도 수정하고 버튼도 추가해줘"처럼 한꺼번에 많이 요청하면 AI가 실수할 확률이 높아집니다.
