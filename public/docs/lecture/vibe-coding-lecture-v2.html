만드는 속도 수일~수주 수분~수시간

2-3 · 네트워크
컴퓨터끼리
어떻게 대화하나
쉬운 비유
인터넷 = 전 세계 도로망
데이터 = 도로를 달리는 택배
IP 주소 = 집 주소
라우터 = 도로 교차로(분기점)
꼭 알아야 할 용어 4가지
IP 주소 인터넷상의 내 컴퓨터 주소. 192.168.0.1 같은 숫자
HTTP/HTTPS 브라우저-서버 간 대화 규칙. S가 붙으면 암호화(자물쇠 🔒)
API 서비스끼리 데이터를 주고받는 창구. "날씨 데이터 주세요"
포트(Port) 건물의 호수. 웹=80, 보안웹=443, 개발용=3000
내가 네이버를 열 때 실제로 일어나는 일
1

2
DNS: "125.209.222.141이야" → IP 주소 반환
3
브라우저 → 네이버 서버: GET / (파일 달라)
4
네이버 서버: 200 OK + HTML 파일 전송 → 화면에 표시
바이브코딩 활용: API를 이해하면 날씨, 지도, 번역, 뉴스 데이터를 가져오는 앱을 만들 수 있습니다.

실습 4 — Claude가 만들어주는 파이썬 코드
Python
import random

정답 = random.randint(1, 100)
시도횟수 = 0

print("🎮 숫자 맞추기 게임 시작!")
print("1~100 사이의 숫자를 맞춰보세요.")

while True:
  추측 = int(input("\n숫자 입력 → "))
  시도횟수 += 1

  if 추측 == 정답:
    print(f"🎉 정답! {시도횟수}번 만에 맞췄어요!")
    break
  elif 추측 < 정답:
    print("⬆️ 더 큰 숫자예요")
  else:
    print("⬇️ 더 작은 숫자예요")
