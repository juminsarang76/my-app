# 동시 작업

> 멀티태스킹 · 병렬 처리 · 동시 협업에 관한 강의 자료

---

## 📌 개요

여러 일을 동시에 진행하는 것은 효율을 올리는 길이지만, 잘못된 방식의 멀티태스킹은 오히려 생산성을 떨어뜨립니다. 이 강의는:

- 진짜 동시 작업 vs 빠른 컨텍스트 스위칭
- 도구를 활용한 작업 병렬화
- 협업에서의 동시 작업 분배
- AI 시대의 동시 작업 패러다임

---

## 📖 목차 (작성 예정)

1. 동시 작업이란 무엇인가
2. 인간의 멀티태스킹 한계와 비용
3. 작업의 의존성 그래프 — 무엇이 병렬 가능한가
4. 도구로 확장하는 동시 작업
   - 자동화 스크립트
   - AI 에이전트 (Claude Code 등)
5. 조직 차원의 동시 작업 — 협업 패턴
6. 실전 사례
